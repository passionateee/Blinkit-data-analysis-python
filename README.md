
# 🛒 Blinkit Sales Data Analysis using Python

This project presents an exploratory data analysis (EDA) of sales data from Blinkit, an Indian grocery delivery service. The goal is to extract actionable business insights from consumer purchase behavior, focusing on sales trends, product types, ratings, and outlet characteristics.

## 📈 Key Highlights:
- **Data Cleaning**: Standardized inconsistent data entries (e.g., item fat content categories).
- **Descriptive Statistics**:
  - Total and average sales
  - Number of items sold
  - Average customer ratings
- **Visual Analysis**:
  - Pie chart of sales by item fat content
  - Bar chart of sales by item type
  - Sales performance by outlet location and item characteristics

## 📊 Business Questions Answered:
- Which product types generate the highest revenue?
- How does fat content impact total sales?
- What is the sales distribution across different outlet types?

## 📁 Dataset:
- `blinkit_data (1).csv` (not included in this repository): Contains sales, rating, and product attribute information.

## 🔧 Technologies Used:
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook

## 🎯 Objectives:
- Understand sales dynamics in the Blinkit ecosystem.
- Visualize patterns in consumer purchasing behavior.
- Provide strategic insights for business decision-making.
